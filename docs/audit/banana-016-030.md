# Voicemeeter Banana manual, pages 16-30

## Selecting Input Devices (p.16)

- **Per-strip input device selector** (p.16): click the "Stereo Input" area on a physical strip to open "Select Input Device #N"; same tabbed layout as the A1 output selector (WDM/WASAPI, KS, MME, ASIO), listing each device with icon, name, description, sample rate/channel count.
- **"Remove Selection" on an input** (p.16): if removed, that strip can still receive audio from a VBAN stream or from ASIO input via the device selected as output A1.
- **Driver recommendation** (p.16): WDM (available since Vista) recommended for best latency/performance; MME only if WDM is absent or not working correctly — MME can add noticeably more input-to-output delay.

## Voicemeeter Virtual I/O (p.17-19)

- **Virtual input wiring** (p.17): Voicemeeter's Virtual Inputs are directly connected to Voicemeeter's virtual audio *playback* devices in Windows Sound (e.g. "VoiceMeeter Input", "VoiceMeeter Aux Input" shown as playback devices).
- **Virtual output wiring** (p.17): Busses B1 & B2 are directly connected to Voicemeeter's virtual audio *recording* devices in Windows Sound (e.g. "VoiceMeeter Output", "VoiceMeeter Aux Output" shown as recording devices).
- **Extended VAIOs (Windows 10+)** (p.18): up to 8 total Virtual I/O. I/O 1 to 5 are a "VAIO extension"; Voicemeeter Input is also Virtual input 6, Voicemeeter Aux input is also Virtual input 7. Voicemeeter's own output is now also exposed as "Voicemeeter out B1" (Virtual output 6) and AUX output as "Voicemeeter.out B2" (Virtual output 7).
- **VAIO Extension licensing** (p.18): VAIO Extensions (the extra virtual I/O beyond the base set) can be activated by an additional license, from the Voicemeeter menu.
- **Virtual ASIO driver** (p.19): each Voicemeeter Virtual I/O also exposes an ASIO interface supporting up to 4 client applications simultaneously. The 4 possible ASIO client sources get signal from BUS B1 (Voicemeeter Virtual ASIO) or BUS B2 (Voicemeeter AUX virtual ASIO); their outputs are mixed together back onto the related Virtual Input (IN4 or IN5), along with any other PC-sourced audio already routed there.
- **Loopback warning** (p.19): recording applications must take care to avoid audio loopback — mute outputs or disable monitoring, otherwise the output signal returns to the input infinitely. Manual shows example DAW (Reaper) and instrument configuration selecting "Voicemeeter Virtual ASIO" as the audio device, with sample rate and buffer size fields (example: 44100 Hz, 512 samples / 11.6ms).

## Audio Controls: hardware-strip 2D panels (p.20-21)

- **IntelliPan Color Panel** (p.20): a 2D pad based on a basic equalizer; dragging changes the "color" of the voice by acting on 3 frequency bands plus a small reverb ("tiny reverb") on the upper half. Axes: horizontal = more bass (left) / more medium (right, described as "more medium" opposite bass) with treble on the vertical axis (up = more treble). Also described as giving "double voice" toward one screen region (top-left area per diagram).
- **Position 3D Panel: Binaural effect** (p.20): right-click the 2D panel to switch to this alternate effect. Positions audio sources with a simple room effect; works in stereo only. Screenshot shows named positions: "Neutral Position", "Pan to Left", "Pan to Right", "Psycho Acoustic Spatialization FX", and a general "3D Panel" with a draggable "Source Position" marker and a "distance"/"Listener" reference point at the bottom center.
- **Modulation Fx panel** (p.21): right-click the 2D panel again (from the Color Panel context, described as available via right-click on "2D Panel") to get the Modulation panel — based on a Chorus effect. Chorus/phasing effects live on the bottom of the pad, modulation on the top; modulation-with-feedback on the left side, simple modulation on the right side; depth is given by distance from the panel's center.
- **Compressor knob** (p.21): per input strip, sets the compression amount; compression uses "auto make up" so it boosts the voice while compressing — compression gain itself is then adjusted by lowering the fader gain. (Shown alongside a separate Gate knob per the Comp./Gate label — Banana's "2 different knobs" from the Introduction section.)
- **Gate knob** (p.21): per input strip, sets the gate/noise-gate effect threshold (paired with the Compressor knob under the shared "Comp. AUDIBILITY Gate" label).
- **Virtual-strip 3-band Equalizer** (p.21): on both Virtual input strips — Treble, Medium (implied "0.0" middle knob), and Bass knobs to boost or remove those bands (labeled "Treble" and "Bass" explicitly in the screenshot; a third unlabeled center knob at "0.0" is presumably Mid).
- **Virtual-strip 5.1 Pan Pot** (p.21): a small 2D panel below the Equalizer on virtual strips; positions the sound source among 5 speaker positions: Front Left, Front Center, Front Right, Rear Left, Rear Right.
- **Strip Limiter** (p.21): Banana adds a Brick Limiter on every physical or virtual strip, with a per-strip threshold. Click directly in the meter bar to set the limit by mouse, or right-click to enter the value directly. Range: -40 to +12 dB.
- **Global control convention: double-click to reset** (p.21): "Trick: All controls go back to default value if double click on it!"

## M.C. and Karaoke buttons (p.22)

- **M.C. button** (p.22): mutes the center channel on a virtual input carrying 5.1/7.1 material (e.g. from a DVD) — mutes channel 3 (CENTER), which typically carries movie dialog; usable for real-time movie dubbing.
- **Karaoke (K) button** (p.22): present on the Virtual AUX input since Banana v2.0.5.3 / Potato v3.0.1.3. Offers 4 real-time algorithms to remove vocals from stereo material, cycled/selected via the button:
  - **K-m (Karaoke Voice Remover)** (p.22): removes the common (center-panned/mono-summed) part of a stereo track — removes all mono-summed sound, not just vocals specifically.
  - **K-1** (p.22): for material where K-m also removes non-voice sounds, K-1 keeps some bass and treble.
  - **K-2** (p.22): like K-1 but keeps more bass and more treble.
  - **K-v** (p.22): last-resort mode for material where nothing else works (e.g. a mono track) — simply filters out the 200-4000 Hz voice frequency range.

## Strip Menu (p.23)

- **Strip context menu** (p.23): right-click the top of an input strip (the INTELLIPAN label for hardware strips, the EQUALIZER label for virtual strips) to open it. Offers 3 kinds of operation on all of a strip's parameters except the slider, Solo/Mute, and bus assignment: **Reset** (all parameters, or a single named effect, back to default), **Copy/Paste** (all parameters or a single effect, from one strip to another), **Save/Load** (all parameters or a single effect, to/from an XML file that can be shared with other users/computers).
- **Hardware-strip menu items** (p.23, screenshot): Reset Strip, Reset INTELLIPAN, Reset Compressor, Reset Gate, Copy All, Copy INTELLIPAN, Copy Compressor, Copy Gate, Paste, Save All, Save INTELLIPAN, Save Compressor, Save Gate, Load...
- **Virtual-strip menu items** (p.23, screenshot): Reset Strip, Reset EQUALIZER, Reset Pan Pot, Copy All, Copy EQUALIZER, Copy Pan Pot, Paste, Save All, Save EQUALIZER, Save Pan Pot, Load... (distinct tool set from the hardware-strip menu, matching each strip type's actual effects).

## Master Section: BUS Assignation (p.24)

- **Ax / Bx routing buttons recap** (p.24): Ax buttons send a strip's source to a physical bus; Bx buttons send it to a virtual bus. BUS A1/A2/A3 connect to physical audio devices; BUS B1/B2 connect to virtual audio outputs (appearing as Windows recording devices).
- **Per-bus BUS Mode button** (p.24): changes the bus's channel content/organization (12 modes total, listed below); Normal mode passes the 8 channels as-is.
- **Per-bus Mono/Cross button** (p.24): first click turns stereo to mono; a second click crosses (swaps) channels 1 and 2 of the bus.
- **Per-bus Master EQ button** (p.24): toggles that bus's Parametric EQ on/off; right-click opens the Master EQ dialog box.
- **Per-bus Mute button** (p.24): mutes the bus.
- **Per-bus Gain Slider** (p.24): adjusts the bus's output volume (dB readout, e.g. "0dB").

## BUS Master Parametric EQ (p.25-26)

- **EQ dialog ("EQpro-G6")** (p.25): opened by right-clicking a bus's EQ button. Provides 6 EQ cells (each with a master gain/delay) across up to 8 channels of the bus.
- **Channel selector** (p.25): "All" or individual channel buttons 1-8; edits apply to all channels together or one specific channel.
- **FLAT button** (p.25): resets the equalizer according to the current channel selector.
- **A/B memory** (p.25): two independent equalization-setting slots, switchable via A/B buttons; EQ edits always apply to whichever preset (A or B) is currently selected.
- **CH.COPY** (p.25): copies EQ settings of the current channel (e.g. to another channel).
- **COPY ALL** (p.25): copies EQ settings of all channels (e.g. to another bus).
- **Direct numeric entry** (p.25): right-click a Gain/Q/Frequency control to open a small edit box for precise manual value entry.
- **EQ button color-coded state indicator** (p.25): Green = channel is equalized or gain-changed; Red = channel is delayed; Yellow = equalized and delayed; Black = nothing applied on that channel.
- **EQ dialog System Menu** (p.26): Restore/Move/Size/Minimize/Maximize/Close (standard window controls) plus **Load EQ Settings** and **Save EQ Settings** — saves/loads as an XML file for the current bus's 8 channels; lets a bus's EQ be copied to another bus or shared with other users.
- **EQ graph right-click menu** (p.26): opens a menu to change the dB scale range of the displayed graph.

## Special Routing Options on Output BUS (p.26-30)

- **MIX DOWN (button)** (p.26): makes a stereo mix-down from 5.1/7.1 sound coming from a DVD player on a virtual input (e.g. strip #3); left and right channels, Center, Sub, and rear are combined down to stereo speaker output.
- **MIX DOWN A** (p.26, p.27, p.30 — formula repeated 3 times identically): rear & side speakers mixed *out of phase* to simulate a surround effect in stereo. Exact processing formula given twice (p.27, p.30): `LEFT = FL + (70% FC) + SW + RL - SL`, `RIGHT = RL + (70% FC) + SW - RR + SR`. Note the manual's formula uses `RL` (rear-left), not `FR` (front-right), on the right-hand side of the RIGHT channel equation — this exact wording is what `docs/SPEC.md` section 1.6 already flags as a likely vendor-documentation typo for `FR`.
- **MIX DOWN B** (p.26, p.27, p.30): rear & side speakers mixed *in phase*. Formula (p.27, p.30): `LEFT = FL + (70% FC) + SW + RL + SL`, `RIGHT = RL + (70% FC) + SW + RR + SR` — same `RL`-not-`FR` wording on the right-hand side.
- **STEREO REPEAT (button)** (p.26, p.30): repeats a stereo signal across all 8 output channels in pairs: channel pair 3,4 / 5,6 / 7,8 all repeat the same stereo content as 1,2. Exact mapping given on p.30: `ch1=FL, ch3=FL, ch5=FL, ch7=FL`, `ch2=FR, ch4=FR, ch6=FR, ch8=FR`.
- **Stereo Repeat + Master EQ as crossover** (p.26-27): in Repeat mode, the Master EQ's 6 cells can be used as a crossover network (via Low Pass / Band Pass / High Pass filter cells) to drive a 2, 3, or 4-way active speaker system, one frequency band per channel pair (diagram: CH1/2 -> Low Pass -> Bass/Amp3, CH3/4 -> Band Pass (LPF+HPF) -> Mids/Amp2, CH5/6 -> High Pass -> High/Amp1).
- **COMPOSITE MODE** (p.28): made for audio post-production. The bus's 8 channels can each be individually composed from any pre-fader or post-fader input (or the bus's own default channel). Configured via the "PATCH COMPOSITE" panel in the System Settings dialog: a row of 8 selector buttons (one per bus channel: BUS ch1, BUS ch2, IN#1 Left, IN#2 Left, IN#3 Left, IN#4 Left, IN#5 Left, IN#5 Right in the screenshot's default) that assigns a specific source to each output channel slot.
- **Composite: pre/post-fader toggle** (p.28): clicking the "Select PRE-Fader Inputs..." text label toggles the whole patch to "Select POST-Fader Inputs..." mode instead — a single click-to-toggle text link, not a separate control per slot.
- **Composite recording use case** (p.28): with a composite signal, up to 8 channels can be recorded from any combination of Voicemeeter inputs (or a DAW connected via Voicemeeter virtual ASIO), e.g. to record a VOIP interview/conference as separate tracks for later post-production.
- **Additional per-bus content BUS Modes (since v2.0.3.4)** (p.29): example use cases given — extract the LFE channel to a subwoofer/Buttkicker/Subpac device, send the 5.1 rear channel to a wireless (Bluetooth) speaker, send the Center channel to a specific speaker device, or use a stereo source to drive a 2.1/4.1/5.1/7.1 PA system. Screenshot shows bus mode buttons including "LFE only" and "Rear only" alongside "Normal mode".
- **Companion tool: "8x8 Gain Matrix"** (p.29): a separate free application (not Voicemeeter itself, downloadable from the vendor forum) providing per-cell gain control over an 8x8 routing matrix (BUS A1/A2/A3/B1/B2 as columns are shown, though the grid is drawn as 8 inputs x 8 outputs), to redistribute all 8 channels of a 5.1/7.1 source from a DVD player or video game.

## All Voicemeeter BUS Modes, full list of 12 (p.30)

Exact formulas as given in the manual, one bus mode per icon+description block:

- **Normal Mode** (p.30): all 8 channels sent as-is.
- **Mix Down A** (p.30): `LEFT = FL + (70% FC) + SW + RL - SL`, `RIGHT = RL + (70% FC) + SW - RR + SR`.
- **Mix Down B** (p.30): `LEFT = FL + (70% FC) + SW + RL + SL`, `RIGHT = RL + (70% FC) + SW + RR + SR`.
- **Stereo Repeat** (p.30): `ch1=FL, ch3=FL, ch5=FL, ch7=FL`, `ch2=FR, ch4=FR, ch6=FR, ch8=FR`.
- **Composite Mode** (p.30): contains pre-fader (or post-fader) inputs as given by the Composite Patch.
- **Up Mix TV (create 7.1 from stereo)** (p.30): `FL=L, FC=20%(L+R), RL=70%(L-R), SL=70%(L-R)`, `FR=R, SW=50%(L+R), RR=70%(R-L), SR=70%(R-L)`.
- **Up Mix 2.1** (p.30): `FL=L, FR=R, SW=50%(L+R)`.
- **Up Mix 4.1** (p.30): `FL=L, FR=R, SW=50%(L+R)`, `RL=L, RR=R`.
- **Up Mix 6.1** (p.30): `FL=L, FR=R, SW=50%(L+R)`, `RL=L, RR=R, SL=L, SR=R`.
- **Center Only (extract Center)** (p.30): `LEFT=FC, RIGHT=FC`.
- **LFE Only (extract sub woofer)** (p.30): `LEFT=SW, RIGHT=SW`.
- **Rear Only (extract rear)** (p.30): `LEFT=RL, RIGHT=RR`.
