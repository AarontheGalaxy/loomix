# Voicemeeter Banana manual, pages 1-15

## General

- **Cover page** (p.1): "VOICEMEETER BANANA — Advanced Virtual Audio Mixer for Windows", version 2.1.2.2, Dec 2025. No control content.
- **Delta-document notice** (p.2): "This Document explains the additional functions added in Voicemeeter Banana (Voicemeeter pro version). If you are not familiar with Voicemeeter, we recommend to read first the User Manual of Voicemeeter Standard version." This manual assumes Standard's baseline and only documents what Banana adds/changes over it.
- **Installation** (p.2): Run setup program, push INSTALL button; if already installed, push REMOVE button first. Must reboot after each install/uninstall operation (the virtual audio device driver requires it to finalize).
- **Update procedure** (p.2-3): Requires full uninstall (REMOVE, reboot) then reinstall (INSTALL, reboot); current settings are preserved automatically, though a manual settings-file backup is suggested. Post-uninstall checklist: verify Voicemeeter virtual audio drivers are gone from Windows Device Manager (game controller section and audio I/O section) and from the Windows Sound dialog's playback/recording device list; VB-CABLE devices, if present, should remain.
- **Post-reinstall checklist** (p.3): check Windows default playback/recording device, check softphone app device selection (Skype/Zoom/Discord), reply to the firewall authorization prompt if the VBAN service is running, re-check System Tray/Run-at-Startup/Show-App-on-Startup options.
- **Pricing model** (p.3): "Fair Trade, Affordable For Everyone" — Voicemeeter is donationware, free to download and use, price adjustable to means/usage.
- **Supported OS/APIs** (p.3): Windows XP (SP2), Vista, 7, 8, 8.1, 10, 32/64 bits; audio APIs MME, DX, WDM/WASAPI, KS, ASIO.
- **Table of contents** (p.4-7): navigation only, no distinct control content beyond what's covered in the body sections below.

## Introduction (p.8)

- **Topology** (p.8): Banana manages 5 audio inputs (3 physical + 2 virtual) and 5 audio outputs (3 physical + 2 virtual) through 5 multichannel busses: A1, A2, A3, B1, B2.
- **Integrated recorder** (p.8): generates BWF, WAV, AIFF, or MP3 in stereo; 4, 6, or 8 channels for WAV/AIFF. Recording options: any pre-fader input(s) or a post-fader BUS. Composite Mode allows recording pre- or post-fader inputs in multichannel mode.
- **Bus parametric EQ** (p.8): 6-cell full parametric EQ on every BUS, with independent equalization possible per channel (1 to 8) — intended for correcting a P.A. system from mono to 7.1. Combined with Stereo Repeat Mode, usable as a stereo crossover to drive 2, 3, or 4-way active speaker systems.
- **Compression/Gate control** (p.8): Banana presents 2 separate knobs for Compression and Gate (vs. presumably one combined control in Standard) and adds a Modulation FX panel on the 3 physical input strips.

## Routing matrix (p.10)

- **Per-strip bus-assign buttons** (p.10): 5 push buttons per strip — A1, A2, A3, B1, B2 — to send that strip's audio to any bus (mix-minus capable per strip).
- **Bus destinations** (p.10): A1 -> Physical Output #1 (Select Audio Device); A2 -> Physical Output #2; A3 -> Physical Output #3; B1 -> Virtual Output (Voicemeeter VAIO); B2 -> Virtual AUX Output (Voicemeeter Aux VAIO).
- **Strip inputs** (p.10): IN1-IN3 physical hardware inputs; IN4-IN5 virtual inputs (Voicemeeter VAIO / Voicemeeter AUX).
- **Master section per-bus controls** (p.10, screenshot): Normal-mode toggle (implies other modes selectable), Mono button, EQ button, Mute button, per-bus Fader Gain slider with numeric dB readout, distinct per-bus row for each of A1/A2/A3/B1/B2.

## Voicemeeter VAIO / audio interfaces (p.11)

- **VAIO ports** (p.11): Virtual Audio I/O exposed on Input #4, Input #5, and on BUS B1/B2; supports MME, KS, DirectX, WaveRT, WDM/WASAPI, ASIO. Up to 4 client applications can use the ASIO virtual driver simultaneously; 8-channel virtual ASIO output for those 4 clients.
- **MME** (p.11): Windows Multimedia API, the first universal Windows audio API; expected latency ~100ms; works with any device.
- **WDM (WASAPI)** (p.11): latest Microsoft audio API; best performance and latency (<30ms); available since Windows Vista.
- **KS (Kernel Streaming)** (p.11): low-latency audio streaming since Windows XP; not supported by all audio devices.
- **WaveRT** (p.11): WaveRT miniport driver, supported Vista and later; good performance, latency comparable to KS.
- **Direct-X** (p.11): used by video games and some audio software; latency usually comparable to MME.
- **ASIO** (p.11): Audio Stream Input/Output, Steinberg's low-latency, high-fidelity sound-card driver protocol.

## Audio hub / Remote control (p.12)

- **VBAN** (p.12): send/receive audio stream over IP to/from any computer on the local network.
- **Voicemeeter Remote API** (p.12): lets client applications develop against Voicemeeter, interconnecting with all audio interface types, device aggregation, mixing/routing functions, MIDI and VBAN features.
- **Macro Button Application** (p.12): installed alongside Voicemeeter; programmable buttons that act on Voicemeeter via a simple request script, allowing complex actions in one click.
- **VoicemeeterRemote.dll / VoicemeeterRemote64.dll** (p.12): installed for client applications that want to control Voicemeeter programmatically. SDK download available on the vendor forum.

## Quick Startup Guide (p.13)

- **Step 1: Install** (p.13): run installer, reboot.
- **Step 2: Configure default audio device** (p.13): set "Voicemeeter Input" as the Windows default playback device.
- **Step 3: Launch Voicemeeter** (p.13): select the audio device for output A1.
- **Step 4: System Tray option** (p.13): set Voicemeeter to run in the System Tray (Run at Startup) to replace the Windows audio mixer; the menu shown also lists: Restart Audio Engine, Load Settings, Save Settings, Reset Settings (Re-Initialize), System Tray (Run at Startup) [checked], Show App on Startup, Always Visible, MacroButtons: Run on Voicemeeter start, Hook Volume Keys (for Level Output A1), Hook Volume Keys (for Level Input #1).
- **Troubleshooting note** (p.13): installing Voicemeeter installs an audio driver, which Windows may set as the new default playback device, silencing normal audio until Voicemeeter is configured and running. Fix is entirely a matter of audio configuration in Windows Control Panel / Sound dialog (default playback + default recording device); for VOIP apps the Communications option must be set to "Do Nothing".

## Connecting Voicemeeter to Audio device (p.14)

- **Internal clock fallback** (p.14): Voicemeeter can run with no audio device at all, using its own internal clock, if no device is selected on output A1.
- **A1 output device selection** (p.14): clicking the A1 button opens a device selector; ASIO or WDM recommended first for best latency.
- **WDM/KS exclusive mode** (p.14): WDM and KS playback devices are used in exclusive mode by default, bypassing the Windows mixer and possibly its own volume control.
- **"Select A1 Output Device" dialog** (p.14, screenshot): left-side tabs group devices by interface type — WDM (WASAPI), KS (Kernel Streaming), MME (Multimedia), ASIO (Steinberg); each device row shows an icon, device name, description, and its sample rate/channel count (e.g. "44100 Hz, 2 Ch", "48000 Hz, 2 Ch"). Buttons: "Open Windows Sound", "Remove Selection", "Exit / Cancel".
- **A1 output device sample rates** (p.14): 32 kHz, 44.1 kHz, 48 kHz, 88.2 kHz, 96 kHz, 176.4 kHz, or 192 kHz. This becomes the main sample rate for the entire mixing engine and for Virtual ASIO points; other inputs/outputs can independently run at any rate.

## Windows Sound integration (p.15)

- **"Open Windows Sound" button** (p.15): opens the Windows Sound dialog box directly from Voicemeeter to adjust system audio configuration/device formats.
- **Sound Properties / Advanced tab format selection** (p.15, screenshot): a dropdown to pick bit depth and sample rate for a device (e.g. "16 bit, 44100 Hz (CD Quality)", "16 bit, 48000 Hz (DVD Quality)"), with a Test button.
- **Windows "Listen" option warning** (p.15): the "Listen to this device" checkbox on a Windows microphone's Listen tab can disturb Voicemeeter routing if left on; manual states it "must be OFF".
- **Windows microphone input level** (p.15): the Levels tab's Microphone slider (0-100-ish range, screenshot shows a value of 79) should be checked/raised if Voicemeeter's input level is too weak; a pre-amp gain control may also apply if available on the device.
