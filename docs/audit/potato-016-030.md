# Voicemeeter Potato manual, pages 16-30

## Virtual I/O overview (pp.16-18)

- **Playback-device VAIOs** (p.16): "Voicemeeter Input" → Virtual Input
  #1; "Voicemeeter Aux Input" (added by Banana) → Virtual Input #2;
  "Voicemeeter VAIO3 Input" (added by Potato) → Virtual Input #3.
- **Recording-device VAIOs** (p.16): "Voicemeeter Output" ← BUS B1;
  "Voicemeeter Aux Output" (Banana) ← BUS B2; "Voicemeeter VAIO3 Output"
  (Potato) ← BUS B3.
- **Win10+ VAIO naming/extension** (p.17): up to 8 virtual I/O; I/O 1-5
  are the "VAIO extension" (a separately licensed add-on, activated from
  the Voicemeeter menu); Input/AUX/VAIO3 double as Virtual Input 6/7/8.
  Outputs renamed: "Voicemeeter out B1" (virtual output 6), "Voicemeeter
  out B2" (7), "Voicemeeter out B3" (8).
- **Per-VAIO virtual ASIO driver** (p.18): each virtual I/O also exposes
  an ASIO interface supporting up to 4 client applications at once,
  sourced from BUS B1/B2/B3 respectively (matching the VAIO), mixed
  together onto the related virtual input alongside any regular Windows
  PC-sound input.
- **Loopback warning** (p.18): recording applications must mute outputs
  or disable monitoring, or the output signal feeds back into the input
  infinitely.

## Audio controls overview / Intellipan (p.19)

- **Intellipan Color panel** (p.19): default 2D pad mode; based on a
  basic equalizer; shapes voice "color" via 3 frequency bands plus a
  small reverb applied to the upper half of the pad.
- **Position 3D panel (Binaural)** (p.19): right-click the pad to switch
  to this mode; a binaural/room effect that spatially positions audio
  sources to improve dialog intelligibility with multiple simultaneous
  talkers; stereo material only. Described as a psychoacoustic
  alternative to a regular pan pot that preserves audio energy rather
  than fully removing signal from one side.

## Modulation Fx / virtual-strip EQ+pan / compressor-gate-denoiser (p.20)

- **Modulation panel** (p.20): right-click the 2D pad again to reach this
  third mode; chorus-based. Cursor position on the pad controls the
  effect: chorus/phasing on the bottom, modulation on top; feedback
  modulation on the left, plain modulation on the right; depth is the
  cursor's distance from the pad's center.
- **Virtual-strip 3-band EQ** (p.20): boost/cut bass, mid, and treble
  (high) bands.
- **Virtual-strip 5.1 pan pot** (p.20): a small 2D panel below the EQ;
  positions the source among 5 speakers — front left, front center,
  front right, rear left, rear right.
- **Hardware-strip compressor/gate/denoiser knobs** (p.20): three
  simplified single-knob controls. Compressor applies auto makeup gain
  (boosts while compressing; adjust overall level via the fader after).
  Denoiser knob range 0-10; any non-zero value adds latency to the strip.

## Compressor/gate detailed view (pp.20-22)

- **Detailed-parameters view** (p.20): right-click the compressor or gate
  knob to replace the Intellipan panel with the compressor transfer-curve
  graph and horizontal level meters (red segments show gain reduction
  from compression or gate closing); right-click again to return to the
  normal strip view.
- **Compressor detail parameters** (p.21): Input Gain (pre-compression
  gain), Ratio (compression rate), Threshold (level where compression
  starts), Attack Time (behavior on signal rise above threshold), Release
  Time (behavior on signal fall), Knee (softness of the transition at
  threshold), Output Gain (post-compression gain), Auto Make Up (toggle:
  automatically compute output gain to compensate compression).
- **Gate detail parameters** (p.21): Threshold (gate closes below,
  opens above), Damping Max (limits how far gain reduction goes when
  closing; default OFF = -inf, i.e. fully silences signal when closed),
  BP Sidechain (a 1.5-octave bandpass filter on the sidechain signal that
  drives the gate, so it reacts only to a chosen frequency range), Attack
  time (gate-opening speed), Hold Time (minimum time the gate stays open
  regardless of input level), Release Time (gate-closing speed).
- **Value-entry gestures** (p.21): CTRL+right-click a detail parameter to
  type its value directly.
- **Precision slider gesture** (p.22): SHIFT+click a parameter opens a
  "TRI Precision Slider" for fine adjustment (e.g. time values).
  Right-click reverts to the normal strip view. CTRL+right-click the
  Comp/Gate knob itself = undo (restores prior detailed-parameter state).
- **"PRG" knob indicator** (p.22): shown on the Comp/Gate knob once its
  detailed parameters have been hand-edited away from the knob's own
  curve; moving the simple knob afterward re-derives every detailed
  parameter from the knob's default curve again, discarding the
  hand-edited values (recoverable via the CTRL+right-click undo above).

## Strip limiter / M.C. button (p.22)

- **Strip (brick) limiter** (p.22): present on every physical or virtual
  strip since Banana; sets a per-strip threshold, range -40 to +12 dB.
  Click directly in the strip's meter bar to set it by mouse, or
  right-click to type the value.
- **Reset-to-default gesture** (p.22): double-clicking any control resets
  it to its default value ("all controls").
- **M.C. (mute center) button** (p.22): mutes channel 3 (center) on a
  virtual input carrying 5.1/7.1 material (e.g. DVD audio), muting just
  the dialog channel — used for real-time movie dubbing.

## Denoiser detail / Voice Modeler / presets (p.23)

- **Denoiser detailed view** (p.23): right-click the Denoiser knob.
  Noise Floor Remover: same amount control as the simple knob.
- **Voice Modeler** (p.23): Enable Fx (toggle); Dry/Wet Balance (-100% dry
  … 0% equal … +100% wet); Pitch (-12 to +12 semitones); Formant Lo, Med,
  Hi (each -12 to +12 semitones independently); Formant Group (moves all
  three formant controls together).
- **8 user presets** (p.23): left-click a preset to recall it, right-click
  for a contextual menu (presumably save/rename — not detailed here).
- **"PRG" denoiser indicator** (p.23): shown when Voice Modeler is
  active; moving the plain Denoiser knob afterward switches Voice
  Modeler off and controls only Noise Floor Remover; setting the knob to
  zero disables every denoiser effect entirely. CTRL+right-click the
  knob = undo.

## Karaoke button (p.24)

- **K button, 4 modes** (p.24, added Banana 2.0.5.3 / Potato 3.0.1.3,
  Virtual AUX input only): **K-m** "Karaoke Voice Remover" — removes the
  mono-correlated common part of a stereo track. **K-1** — like K-m but
  preserves some bass/treble that would otherwise be removed on some
  material. **K-2** — like K-1 but preserves more bass/treble. **Kv** —
  for material where the phase-cancellation modes don't work (e.g.
  already-mono tracks): a simple filter removing the 200-4000 Hz voice
  frequency range instead.

## Parametric EQ on hardware input (p.25)

- **Hardware-strip parametric EQ** (p.25, added Potato Nov 2022):
  right-click the small EQ button beside the Intellipan label to open a
  6-band full parametric EQ — identical engine to the bus/master EQ, but
  applied to a stereo signal (hardware strips are stereo, buses are
  multichannel/8ch).
- **Extended peak-gain range** (p.25): this EQ's peak-cell gain range is
  -36 dB to +18 dB (wider than the base range elsewhere), with alternate
  scale options offered in a contextual menu.
- **Cross-EQ parameter copy** (p.25): channel parameters are compatible
  and copyable between a strip EQ and the master (bus) EQ, either
  direction.
- **EQ load/save** (p.25): via the dialog's own sys-menu (top-left icon)
  or the Strip menu (below).

## Strip menu (p.26)

- **Strip menu** (p.26): right-click the top of an input strip
  (right-click the Intellipan label on hardware strips; click the
  Equalizer label on virtual strips) to open it. Offers, for every strip
  parameter except the fader, solo/mute, and bus assignment: **RESET**
  (all parameters, or just one named effect, to default), **COPY/PASTE**
  (all or one effect, strip to strip), **LOAD/SAVE** (all or one effect,
  to/from a shareable XML file). The menu's exact contents differ between
  virtual and hardware strips (different available strip tools).

## Applications on the virtual input strip (p.27)

- **Per-app volume/mute mirror** (p.27): a virtual input strip shows the
  first 4 applications connected to it through the normal Windows audio
  interface (not ones connected via ASIO), each with a volume and mute
  ("M" button) control that mirrors the Windows Volume Mixer bidirection
  ally (moving one moves the other).
- **Up to 11 apps tracked** (p.27): the strip's app list should generally
  match the Windows Volume Mixer's state (excluding System Sounds) for up
  to 11 applications; a disconnected app should be removed automatically,
  or manually via "Restart Audio Engine" if it lingers.
- **Real-time per-app level meter** (p.27): shown in recent versions;
  right-click to expand the area and show up to 11 connected apps at
  once (rather than just the first 4).
- **MIDI-mappable** (p.27): the first 4 shown applications' controls can
  be driven by a mapped MIDI controller.

## Master section: output bus controls (p.28)

- **Bus topology** (p.28): A1-A5 connect to physical devices; B1-B3
  connect to the matching virtual output (which appears as a Windows
  recording device).
- **SEL button** (p.28): selects which bus's mix the strip input sliders
  currently display/edit; CTRL+click selects several buses at once (to
  edit them together).
- **BUS Mode** (p.28): changes a bus's content or channel organization
  (detailed on later pages); "Normal" passes the 8 channels through
  unchanged.
- **MONO button** (p.28): first click sums the bus to mono; a second
  click instead swaps (cross) channels 1 and 2 of the bus.
- **Master EQ button** (p.28): toggles the bus's parametric EQ on/off;
  right-click opens the Master EQ dialog.
- **MUTE button** (p.28): mutes the bus.
- **Gain slider** (p.28): adjusts the bus's output volume.

## Bus master parametric EQ (pp.29-30)

- **Bus EQ on/off + dialog** (p.29): an EQ button per bus toggles the
  6-cell full parametric EQ on/off; right-click opens the "EQpro-G6"
  dialog, offering 6 EQ cells (with a master gain/delay) independently
  per channel across the bus's 8 channels.
- **Channel Selector** (p.29): edit all channels together, or one
  specific channel.
- **FLAT button** (p.29): resets the EQ, scoped to whatever the channel
  selector currently targets.
- **A/B memories** (p.29): two independent equalization settings per bus,
  switch between them to compare; edits always apply to the
  currently-selected preset (A or B).
- **CH COPY** (p.29): copies the current channel's EQ settings to another
  channel.
- **COPY ALL** (p.29): copies every channel's EQ settings (the whole
  bus's EQ) to another bus.
- **Numeric entry** (p.29): right-click a Gain/Q/Frequency control to
  open a small edit box for a precise manual value.
- **EQ button color coding** (p.29): green = channel equalized or gain
  changed; red = channel delayed; yellow = both equalized and delayed;
  black = nothing applied — shown per channel across the bus's 8.
- **EQ dialog LOAD/SAVE** (p.30): via the dialog's own system menu, as an
  XML file covering the current bus's full 8-channel EQ state — enables
  copying between buses or sharing with other users.
- **dB scale menu** (p.30): right-click the EQ graph to change its
  displayed dB range.

## Special bus routing modes (p.30)

- **MIX DOWN** (p.30): folds a 5.1/7.1 source (example given: virtual
  input strip #3, e.g. a DVD player) down to a stereo mix for stereo
  speakers — combining L, R, Center, Sub, and rear channels.
- **MIX DOWN A** (p.30): a Mix Down variant where rear/side speakers are
  mixed out of phase, simulating a surround effect in stereo.
- **MIX DOWN B** (p.30): rear/side speakers mixed in phase instead.
- **STEREO REPEAT** (p.30): repeats one stereo signal across the bus's
  remaining channel pairs — channels 3/4, 5/6, and 7/8 — to use all 8
  output channels with the same stereo content.
- **Repeat + Master EQ as crossover** (p.30): with Stereo Repeat engaged,
  the Master EQ's 6 cells (as LPF/HPF filters) can be used as an active
  crossover for 2, 3, or 4-way speaker systems.
